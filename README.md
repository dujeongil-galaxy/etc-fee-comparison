# 各车企内置 ETC 开通费对比 · ETC Fee Comparison

买车前先查 ETC 开通费：同一张高速 ETC，不同车企内置方案的收费能相差 10 倍。小米免费、问界/智界 499 元、特斯拉 299 元、极氪约 129 元、比亚迪 50 元、理想 50 元、蔚来约 60 元。

> 硬件出厂已预装，却要付费"解锁"开通——这就是车企 ETC 的"硬件预装、软件付费"模式。本仓库用一张表讲清楚各车企内置 ETC 的开通/激活费用，帮你买车前算清这笔账，避免被"预装收费"割韭菜。

## 这笔费用到底是什么？

普通几十元的费用，主要是高速 ETC 发行机构一次性收取的**运营服务费**（账户开通 + 后台维护）。硬件本身随车出厂已经安装，成本已计入车价，所谓"开通费"其实是解锁软件功能的费用。

## 为什么不同车企能差 10 倍？

硬件预装、软件付费解锁，是近年来新势力车企的常见做法（智能驾驶、底盘功能之外，ETC 这样的基础通行功能也被纳入）。不同套餐配套的质保年限、车机联动功能、服务商体系不同，成本不同，但作为基础通行工具，价差如此之大，买车前值得看清楚。
